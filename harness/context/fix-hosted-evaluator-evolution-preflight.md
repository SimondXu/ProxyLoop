## Frozen design

1. New `ml/evaluation/src/proxyloop_evaluation/hosted_rescore.py`:
   - `check_r4_integrity(root) -> tuple[bool, tuple[str, ...]]`: r4 file
     present; `report_fingerprint_r4`; r2/r3 source fingerprints and
     timestamps; nested matrix fingerprint; deterministic conditions equal
     r3; catalog/manifest/episode/ceiling fingerprints equal r3;
     `_provider_error_reconciliation_errors`; probe prompt/schema
     fingerprints. **No fresh-fixture replay.** Each check calls the
     existing helper in the frozen `hosted_rerun` module (import, never
     copy).
   - `execution_contract_state(root) -> dict`: `{"r4_fingerprint",
     "current_fingerprint", "state": "unchanged" | "drifted_since_r4",
     "drifted_paths": [...]}` — reported, never a failure.
   - `derive_rescored_r4(r4, *, fixtures) -> EvaluationReportV2`: for every
     succeeded/failed condition run the **current** evaluator through
     `replay_v2._replay_condition` over the stored raw outputs, preserving
     source evidence per row (`_preserve_source_evidence` pattern from
     `derive_r3_report_from_r2`); `schema_version="phase-03a1-r4-rescored-v1"`,
     `source_report_fingerprint=r4.report_fingerprint`,
     `evaluator_version=f"phase-03a1-rescore::{PROVIDER_VERIFIER_VERSION}"`,
     `new_external_dispatch_count=0`, and per-condition diagnostics
     `rows_changed_vs_r4` (episode ids whose `end_to_end_valid`,
     `provider_outcome_valid` or `failure_codes` differ from r4).
   - `check_rescored_artifact(root)`: committed
     `data/evaluation/phase-03a1-r4-rescored-report.json` is byte-equal to
     the in-memory derivation and its `source_report_fingerprint` equals
     the committed r4's.
2. New `scripts/run_phase_03a1_hosted_rescore.py` with `--write` / `--check`
   (`--check` = integrity + contract state printed + rescored artifact).
3. `Makefile`: `hosted-rerun-check` recipe → `python -m
   scripts.run_phase_03a1_hosted_rescore --check`; new `hosted-rescore`
   (`--write`) and `hosted-rescore-check`; `hosted-rerun-source-check`
   unchanged; the frozen `run_phase_03a1_hosted_rerun --check` stays
   runnable but leaves `make test`/`preflight` (documented as the r4-era
   gate).
4. r1: `baselines-check` leaves `make test`; new `baselines-historical-check`
   = `artifacts.check_baseline_artifacts` minus `replay_report` (integrity
   only; `artifacts.py`/`replay.py` are not frozen).
5. `runtime/packages/provider_simulator/.../environment.py`: add
   `PROVIDER_VERIFIER_VERSION = "phase-01b-verifier-v1-label"` (G2c bumps
   it) and export it.
6. `docs/ml-evidence.md`: r4 row — "numbers are the r4-era evaluator's
   (frozen bytes; `make hosted-rerun-check` reports unchanged /
   drifted-since-r4); the current evaluator's reading of the same raw
   outputs is `phase-03a1-r4-rescored-report.json` (0 external calls),
   regenerated by `make hosted-rescore` whenever the evaluator changes";
   r1 row — "historical; integrity-checked, not replayed"; r5 unchanged.

With the verifier unchanged in this PR the committed rescored artifact
must equal r4 row for row (`rows_changed_vs_r4` empty for every condition)
— that is the proof the mechanism itself is neutral.

## Regression tests (`ml/tests/test_hosted_rescore.py`, write first)

- Rescore check rejects a tampered rescored artifact (one flipped row; a
  refreshed fingerprint) and a wrong `source_report_fingerprint`.
- The integrity entry point rejects the same tamper cases
  `ml/tests/test_hosted_rerun.py` (~:314-380) uses against the old gate.
- In a tmp copy of the tree, modifying any frozen file makes
  `execution_contract_state` report `drifted_since_r4` listing that path;
  unmodified → `unchanged`.
- With the current evaluator, `derive_rescored_r4` yields
  `rows_changed_vs_r4 == ()` for every condition.
- `baselines-historical-check` passes without importing `replay`.

any need to change `EvaluationReportV2`'s schema beyond the new
`schema_version` literal and the `rows_changed_vs_r4` diagnostics; a
rescore that is not row-for-row equal to r4 in this PR.
