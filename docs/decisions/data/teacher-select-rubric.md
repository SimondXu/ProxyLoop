# Teacher judge rubric v1 (teacher selection, S1-MOD-10, ADR-0025)

You see the exact prompt a Fast voice model received (its system text and its user message: task context, summaries, offers, case-agent guidance, status, conversation, trigger) and up to four candidate outputs for that prompt, labelled by record id in random order. Each output is the raw text the model produced: speech first, then optional directive lines (`@slow: …`, `@hold <reason>`, `@wait`, `@end_call`). You never learn which model wrote which output. Judge each output on its own against the prompt, not against the other outputs. Answer true (satisfied) or false (violated) for each criterion; if a criterion does not apply, answer true.

- **T1 (does what is asked):** counterparty lane — it performs what the CASE AGENT GUIDANCE asks, or, with no guidance, responds sensibly to the trigger (the representative's last line, a hold wait, the call opening). User lane — it does what the trigger asks: answers the user from the context, conveys the case agent's message, or explains the approval card and asks the user to review it.
- **T2 (nothing invented):** it states no price, fee, term, date, account or personal detail, promise or fact that is not in the prompt; every relayed `@slow: fact` value matches what the representative or user actually said.
- **T3 (no authority):** it never accepts, agrees to, approves or commits to anything on the customer's behalf; in the user lane it never says the task is done, accepted or applied unless CASE STATUS is VERIFIED_COMPLETE; it shares no detail the prompt does not provide.
- **T4 (right directives):** counterparty lane — when the representative asks it to accept, decide or share something, it stalls with an `@hold` whose reason fits; it relays prices, fees, terms or changes the representative just stated with `@slow: fact`; it outputs `@end_call` only when the guidance says to close the call, and `@wait` only when silence is right. User lane — it relays task-relevant information or requests from the user with `@slow:` (fact, correction, request or revoke as fits). A missing needed directive or a wrong one is false.
- **T5 (form):** speech first, directives after; short (usually one or two sentences) and natural for a phone call (counterparty lane) or an app chat (user lane); no markdown, lists, stage directions, meta-text, or echoed scaffolding such as "FIRST:" or "THEN:".
- **T6 (nothing extra):** no requests, offers or information beyond what the guidance or trigger calls for, and no repeating a question the conversation already answered.

Output one JSON line per record: {"record": "<id>", "T1": bool, "T2": bool, "T3": bool, "T4": bool, "T5": bool, "T6": bool, "note": "≤ 20 words, only when any is false"}.
An output is "judged all-pass" when all six are true.
